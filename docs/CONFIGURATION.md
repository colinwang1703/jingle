# 🔔 Jingle 配置文件说明 (Configuration Guide)

`bells.conf` 是 Jingle 系统的核心配置文件，用于定义何时播放什么铃声或音乐。

## 📄 文件位置
- 路径: `config/bells.conf`
- 编码: UTF-8

## 📝 语法格式
每一行代表一个播放计划，基本格式如下：

```text
(周几限制) 音频文件, 时间点1, 时间点2, ...
```

### 1. 周几限制 (可选)
指定在一周的哪几天播放。如果省略，则默认**每天**播放。
- 格式: `(数字列表)`
- 范围: 1 (周一) 到 7 (周日)
- 示例:
    - `(1,2,3,4,5)` -> 周一至周五
    - `(6,7)` -> 周末
    - `(1)` -> 仅周一

### 2. 音频文件 (必填)
指定要播放的音乐文件。文件必须位于 `music/` 目录下。
- **单曲播放**: 直接写文件名。
    - 示例: `class_bell.mp3`
- **随机播放**: 使用方括号包裹多个文件名，系统会在播放时随机选择一首。
    - 示例: `[song1.mp3, song2.mp3, song3.mp3]`

### 3. 时间点 (必填)
指定播放的具体时间，24小时制。
- 格式: `HH:MM`
- 示例: `08:00`, `14:30`
- **临时禁用**: 在时间点前加 `-` 可以临时跳过该时间点。
    - 示例: `-08:00` (不会播放)

---

## 💡 配置示例

### 场景 1: 上下课铃声 (周一至周五)
```text
# 周一到周五，早上8点和8点45播放上课铃
(1,2,3,4,5) class_bell.mp3, 08:00, 08:45
```

### 场景 2: 起床铃 (每天)
```text
# 每天早上7点播放
morning_alarm.mp3, 07:00
```

### 场景 3: 课间音乐 (随机播放)
```text
# 每天上午10点，从列表中随机选一首播放
[pop.mp3, jazz.mp3, rock.mp3], 10:00
```

### 场景 4: 周末特定活动
```text
# 仅周六周日中午12点播放
(6,7) lunch_time.mp3, 12:00
```

---

## ⚠️ 注意事项
1. `#` 开头的行会被视为注释，不会生效。
2. 文件名必须与 `music/` 目录下的实际文件名完全一致（区分大小写）。
3. 时间格式必须严格为 `HH:MM`。
4. 建议使用 Web 管理界面进行配置，可以避免语法错误。
